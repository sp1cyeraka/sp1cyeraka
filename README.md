# I'm sp1cyeraka 👋

I build web tools and small utilities, mostly with TypeScript and Node.js, usually backed by SQLite because honestly it handles more than people give it credit for. I'm drawn to the indie web — the idea that you can ship something useful without a massive stack or a team of ten. Lately I've been thinking a lot about what it means to build pragmatically, choosing the boring thing that works over the shiny thing that might.
